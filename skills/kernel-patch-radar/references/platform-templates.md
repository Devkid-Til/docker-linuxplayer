# 多平台内容模板 — 从一份核心内容改写为各平台内容稿

**职责边界**：本文件只负责**平台内容稿**（文本：语气/长度/结构适配），**不含任何视觉排版（HTML/CSS）**。需要 HTML/视觉呈现的平台（当前仅公众号）排版统一调用 skill `wechat-article`；本 skill（kernel-patch-radar）只产内容稿，不产排版。

**原则**：所有平台基于**同一份核心内容**（含时间标注、六步弧线、概念速查），只做语气/长度/结构适配，**事实与时间不变**。目前以文字为主；图形（SVG / mermaid / 流程图）后续走飞书画板，视频用外部视频生成工具。

## 通用改写铁律
- 事实、标题、时间标注（北京时区）不改，来源如实
- 术语解释保留（各平台读者多为非内核背景，概念速查要跟着走）
- 每平台**独立成文**，不互相引用
- 尊重平台规矩：公众号原创、小红书敏感词、抖音时长节奏

## 1. 微信公众号（长文 · 深度 · 首选）
完整生产级规格见 `wechat-template.md`（标题 / 摘要 / 封面 / 结构 / CTA / 样稿）。要点：
- 标题 `Linux内核玩家 · MM月DD日｜<看点>` **≤ 40 字**（feed 展示约 30 字截断，看点放最前）；显式给摘要（≤ 54 字）
- 公众号视觉排版全部交给 skill `wechat-article`，本文件不含排版规则
- 结构：导语 → 今日导读 → 头条（六步弧线）→ 两栏目 → 机制雷达 → 概念速查 → CTA

## 2. 小红书（种草帖 · 短）
- **标题**（≤20 字，带 emoji/感叹）：`程序员都在追的「Linux内核玩家」🔥 今日 3 大看点`
- **正文**：5-8 短段，每段 1-2 句；开头第一句是钩子（「今天内核圈又出大事了…」）
- **风格**：口语、有情绪；把六步弧线压缩成「它干了啥 / 为什么值得看」两问
- **结尾**：收藏/关注引导 + 话题标签（#Linux #内核 #开源 #程序员 #技术）
- **封面**：一句话大字（可后续用飞书画板做 SVG 封面）

## 3. 抖音（口播脚本 · 60-90 秒）
- **开头钩子**（0-3 秒）：一句话抓人（「今天 Linux 内核圈，一个大新闻…」）
- **正文**（3-60 秒）：3-4 段口播，每段 10-15 秒；用大白话讲「发生了什么 + 为什么重要」
- **画面建议**：每段一行（如「代码画面 / 框架图 / 你的反应」）
- **结尾**（60-75 秒）：引导（「关注我，每天 60 秒看懂内核动态」）
- **风格**：口语、短句、有节奏；术语全换成大白话

## 4. GitHub（Markdown 日报 · 归档）
- **文件名**：`daily/YYYY-MM-DD.md`（frontmatter：date / sources / 数据截至）
- **结构**：完整核心简报（含时间标注）+「数据来源与脚本」一节（radar.sh、lore git 通道）
- **用途**：沉淀知识库、可搜索、可追溯；供人订阅
- **README 索引**：按日期追加链接

## 产出物清单（一次成文产出 4 份）
1. 微信长文（.md，可直接贴公众号编辑器）
2. 小红书帖（含标题 / 正文 / 标签）
3. 抖音脚本（含分段口播 + 画面建议）
4. GitHub 日报（.md 文件，留待 push）
