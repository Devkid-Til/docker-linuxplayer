## 三、内容编辑标准（内容层产出字段；wechat-article 只渲染、不新写观点）

- **钩子标题**（头条必产）：读者能懂的钩子句，不用补丁名/commit subject（例：`media: add virtio-media driver` → 「虚拟机里的摄像头，终于要成标准设备了」）；补丁名作为出处随标题提供。
- **一句话点评**（头条必产）：一句作者视角观点，与事实严格区分。
- **和你相关**（亮点必产）：一句和目标读者的关系。
- **六步弧线**（头条）：现状 / 痛点 / 方案 / 为什么 / 效益 / 下一步；**压缩弧线**（亮点）：定位 / 做法 / 效益。（详见「分析规则」）
- **○ 常规动态**：只列标题 + 时间 + **可点原文链接**（lore URL，去掉尖括号）；不值得展开的才进这里。
- **时间标注**：北京时间 MM-DD HH:MM；数据截至时间放文末。
- **原文链接**：lore URL 去掉尖括号提供（`<...>` 是消息展示格式，去掉才是可访问地址）。
- **架构优先**：机制级改动（新框架/API/重构）优先于驱动小修；术语首现给一句话解释。
- **标题/摘要字数**：标题 `Linux内核玩家 · MM月DD日｜<看点>` ≤40 字；摘要 ≤54 字（见「发布信息」）。
- **归属边界**：以上字段（含钩子标题/点评/和你相关）均在**内容层**产出；wechat-article 只渲染样式，不代笔观点文字。
